# Шарага — приложение и папка заданий

Личный учебный органайзер для группы Б-ОРМ-41 (КГУ) и папка-обменник с ассистентом.

Приложение: **https://storytailer.github.io/sharaga/**

## Структура
- `index.html` — приложение «Шарага» (открывается в браузере/на iPhone).
- `sw.js` — service worker: офлайн-режим и приём push-уведомлений.
- `assets/logo.png` — логотип КГУ.
- `дз/` — сюда кладётся экспортированный из приложения файл `домашка.json`.
- `готовые/` — готовые работы по предметам, которые подготавливает ассистент.
- `cloud/ready.json` — зеркало облака на GitHub Pages (канал «на чтение», когда воркер недоступен).
- `.github/workflows/push-reminders.yml` — отправка push-напоминаний о парах.
- `.github/scripts/send-reminders.js` — сам отправщик.

## Синхронизация с папкой
1. В приложении пишешь ДЗ у нужной пары.
2. **«⬆ В облако»** — задания уходят ассистенту. Если сеть закрыла канал, они
   встают в очередь и уходят сами при первой возможности; ничего не теряется.
   Совсем запасной путь — **«📤 Отправить файлом»**: `домашка.json` уходит через
   «Поделиться» в любой мессенджер.
3. Ассистент читает задания, кладёт готовые работы в `готовые/{предмет}/`
   и заливает их обратно в облако.
4. **«⬇ Из облака»** — готовые появляются у нужных пар.

## Как устроены напоминания

Есть два независимых механизма — это важно, они чинят разные случаи.

**1. Push с сервера — работает, когда приложение закрыто.**
Отправляет GitHub Actions (`push-reminders.yml`, cron каждые 5 минут):
- берёт расписание прямо из `PAIRS` в `index.html` — второго источника правды нет;
- забирает подписки устройств из Cloudflare-воркера (`/api/subs`);
- шлёт Web Push, подписанный VAPID-ключом из секретов репозитория;
- отметки об отправленном лежат в ветке `push-state` (файл `sent.json`),
  поэтому одно и то же напоминание не приходит дважды;
- утром (около 07:00 МСК) присылает список пар на день.

Расписание в `index.html` записано в местном времени; часовой пояс задан
переменной `TZ_OFFSET_MIN` в workflow (сейчас 180 — UTC+3, Москва).
Напоминание приходит за 10–25 минут до пары. `LEAD_MIN` — желаемый запас,
`GRACE_MIN` — поправка на задержку планировщика: GitHub обещает запуск раз
в 5 минут, а по факту запускает раз в 10–14 минут. Окно поиска пар равно
`LEAD_MIN + GRACE_MIN` и должно оставаться шире самого большого пропуска,
иначе напоминание проскочит между запусками.

Секреты репозитория: `VAPID_PUBLIC`, `VAPID_PRIVATE`, `SYNC_KEY`.
Публичный VAPID-ключ продублирован в `index.html` (константа `VAPID_PUBLIC`) —
**при смене ключа нужно менять оба места**, иначе старые подписки перестанут
приниматься и приложение молча останется без пушей.

Проверить отправку вручную: вкладка Actions → «Push-напоминания о парах» →
Run workflow → включить галочку «Отправить тестовое уведомление».

**2. Отсчёт внутри приложения** — работает, только пока приложение открыто.
Показывает «До пары: …» и всплывающее напоминание. Интервал задаётся в настройках.

### Что нужно на iPhone
Push приходит **только** приложению, добавленному на Главный экран
(Safari → «Поделиться» → «На экран „Домой“») на iOS 16.4+. Из вкладки Safari
пуши не работают — это ограничение самой iOS, а не приложения.

## Диагностика
Вкладка «Задания» → **🩺 Диагностика** → «Проверить всё». Показывает по пунктам:
запущено ли приложение с Главного экрана, есть ли разрешение на уведомления,
жива ли push-подписка и актуальным ли ключом она сделана, какие каналы связи
отвечают, а какие закрыты. Кнопка «📋 Скопировать отчёт» — чтобы прислать
результат ассистенту.

## Известные ограничения
- `*.workers.dev` бывает закрыт у мобильных операторов. Чтение обходится через
  зеркало на GitHub Pages, запись — через очередь с автодосылом и отправку файлом.
  Включать push лучше с Wi-Fi: подписка регистрируется через воркер.
- GitHub отключает cron в репозитории, где 60 дней не было активности.
  Отправщик коммитит состояние в ветку `push-state`, так что в учебные дни
  активность есть; после долгих каникул cron может понадобиться включить заново.
- Запуск cron GitHub задерживает на несколько минут — поэтому напоминание
  приходит с запасом, а не ровно за N минут.
