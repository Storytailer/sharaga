# Шарага — приложение и папка заданий

Здесь живёт личный учебный органайзер для группы Б-ОРМ-41 (КГУ) и папка-обменник с ассистентом.

## Структура
- `index.html` — приложение «Шарага» (открывается в браузере/на iPhone).
- `assets/logo.png` — логотип КГУ.
- `дз/` — сюда кладёшь экспортированный из приложения файл `домашка.json` (все задания и готовые работы).
- `готовые/` — готовые работы по предметам, которые подготавливает ассистент.

## Как работает синхронизация с папкой
1. В приложении (вкладка «Задания») пишешь ДЗ у нужной пары.
2. Жмёшь **«Экспорт»** → скачивается файл `домашка.json`. Кладёшь его в папку `дз/`.
3. Ассистент читает `дз/домашка.json`, видит задания, подготавливает готовые работы в `готовые/{предмет}/`.
4. Когда готовое готово — оно попадает обратно в JSON (обновлённый `домашка.json` в `дз/`).
5. Открываешь его в приложении кнопкой **«Импорт»** → готовое появляется у нужной пары (снизу в карточке).

То есть: что записал в приложении → автоматически в папку (через экспорт), что сделали → назад в приложение (через импорт).
