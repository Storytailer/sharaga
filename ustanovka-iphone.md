# Установка «Шараги» на iPhone (PWA)

## Что понадобится
- Файлы приложения (папка `university`): `index.html`, `manifest.webmanifest`, `sw.js`, папка `assets/`.
- Доступ к iCloud Drive на iPhone (Safari / «Файлы»).

## Как положить файлы на iPhone (вариант через iCloud Drive)
1. На компьютере скопируй всю папку `university` в **iCloud Drive** (например, в `iCloud Drive/университет` или прямо в общую папку).
2. На iPhone открой приложение **«Файлы»** → iCloud Drive → найди `university`.
3. Тапни по папке, внутри найди `index.html`.

## Как сделать иконку-приложение (главный экран)
> Важно честно: сервис-воркер (полный офлайн-кэш) работает только при открытии через **https**, а не с локального файла из «Файлов». Но добавление на Главный экран и работа интерфейса + данных (ДЗ в localStorage) будет работать в любом случае.

### Способ 1 — открыть файл и добавить на экран
1. В «Файлах» тапни на `index.html` → откроется в Safari.
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. В меню выбери **«На экран “Домой”»** (Add to Home Screen).
4. Название — «Шарага», иконка — логотип КГУ. Нажми «Добавить».
5. На рабочем столе появится иконка «Шарага» — открываешь её как приложение.

### Способ 2 — (рекомендую для стабильного офлайна) открыть через адрес
Если разместить папку на любом https-хостинге (GitHub Pages, Netlify и т.п.), то:
- открываешь URL в Safari,
- «Поделиться» → «На экран “Домой”»,
- и уже будет полноценный офлайн-режим через сервис-воркер.

## После установки
- Внутри приложения: вкладка «Расписание» — сегодня и календарь по неделям; вкладка «Задания» — экспорт/импорт `домашка.json` для обмена с папкой `dz/`.
- Данные (ДЗ, готовые) хранятся на устройстве (localStorage) и переносятся через файл `домашка.json`.
